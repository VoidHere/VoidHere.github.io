Extract pages from a PDF

Pull selected pages out of a PDF into a new document, without touching the original file.

Runs on your device No uploads, ever Free, no account
The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Drop the PDF

    The tool reads the page count so you know what you're working with.

  2. Name the pages

    Type a selection like 2,5,6-9. That order is kept in the new file.

  3. Download the extract

    You get a fresh PDF with only those pages. The original on disk is never modified.

Questions people actually ask

Can I extract pages in reverse order?

Yes — '9-6' works and writes the pages back to front. Type it exactly as 9-6.

How is this different from splitting?

Splitting cuts one PDF into many. Extracting pulls a selection into one new file and leaves it at that.
