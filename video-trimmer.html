Trim a video

Keep the goal, cut the walk-back. Set the start and end seconds and take exactly that slice.

Runs on your device No uploads, ever Free, no account
The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Drop a video

    The duration is read out so you can plan the cut.

  2. Set start and end

    In seconds, or in minutes-and-seconds format, e.g. 1:30. The preview player helps you find the moment.

  3. Trim and download

    You get exactly the slice, fast, because the untouched parts aren't re-encoded.

Questions people actually ask

Does trimming re-encode the video?

Where possible, no — the file is cut at keyframes and copied as-is, which is fast and lossless. Precision trimming of a couple of seconds may trigger a light re-encode.

Can I save multiple clips in one go?

One clip per pass for now; run the tool again on the same video for the next highlight.
