URL encode and decode

Percent-encode the awkward characters in URLs, or unpack an encoded link so it's readable again.

Runs on your device No uploads, ever Free, no account
The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Paste a URL or fragment

    A full link, a query value, or a path segment.

  2. Pick the mode

    Component mode for values (spaces become %20); full-URL mode keeps :/?&= structure intact.

  3. Copy either direction

    Decoding works on anything percent-encoded you feed it.

Questions people actually ask

encodeURIComponent or encodeURI?

Both, via the mode switch. The first for values you're assembling into a URL, the second for an entire URL you're passing along.

+ or %20 for spaces?

Both appear in the wild; %20 is the standard form. When decoding, both are understood.
