Create a ZIP archive

Gather loose files — or a whole folder — into one tidy ZIP, with per-file compression you can set.

Runs on your device No uploads, ever Free, no account
The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Drop files, or choose a folder

    Folder mode keeps the whole structure inside the ZIP — subdirectories and all.

  2. Set the compression

    Maximum for documents, fast for photos and anything already compressed.

  3. Download the ZIP

    Named how you like, sized how you see — the final size is shown before download.

Questions people actually ask

How much will it compress?

Text, code and documents shrink a lot. JPGs, MP4s and other already-compressed files barely move — the ZIP is still worth it for bundling, not size.

How big can it be?

Memory-bound: a couple of GB of files is realistic on a modern machine.
