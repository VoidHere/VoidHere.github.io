Convert Base64 back to an image

Pasted data URI or raw Base64 — decoded into a real image file you can save.

Runs on your device No uploads, ever Free, no account
The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Paste the Base64

    With or without the data:image/... header — the tool works either way.

  2. Check the preview

    If it's valid, you'll see the image. If not, you'll see exactly what's wrong with the input.

  3. Save the file

    The original format is detected from the data itself.

Questions people actually ask

It says the Base64 is invalid. Now what?

Usual suspects: the string is truncated, wrapped in quotes, or has stray whitespace mid-string. Everything after 'base64,' is the part that matters.

Can it decode huge strings?

Yes, within browser memory — several MB of Base64 is routine.
