The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Paste your JSON

    An array of objects, or an object with arrays inside.

  2. Check the preview

    The table preview shows exactly what the CSV will contain.

  3. Download the CSV

    Ready for Excel, Sheets or a database import.

Questions people actually ask

What if objects have different keys?

The CSV gets the union of all keys, so no column disappears just because the first row lacked it.

Commas and quotes inside values?

Everything is properly quoted per CSV rules — the file won't shred itself in Excel.
