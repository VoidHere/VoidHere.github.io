The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Drop an image

    Keep it small — data URIs live inside your code, so every byte is paid for twice.

  2. Copy the flavour you need

    Raw Base64, an HTML img tag, a CSS background, or Markdown.

  3. Paste into your project

    No files to keep. That's the point and the trade.

Questions people actually ask

When is Base64 a good idea?

Tiny icons and UI bullets that save a request. Not photos — the same bytes inflated by a third, in a file you can't cache separately.

Is anything sent anywhere?

No. The conversion is base arithmetic the browser does locally.
