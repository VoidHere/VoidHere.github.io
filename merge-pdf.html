Merge PDF files

Combine several PDFs into one document. Drag them into the order you want, or let the file list decide.

Runs on your device No uploads, ever Free, no account
The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Add your PDFs

    Drop two or more PDF files onto the cutting board. They stay in your browser the whole time.

  2. Set the order

    New files land at the bottom. Use the arrows on each file to move it up or down.

  3. Merge and download

    Press Merge. The combined file downloads straight away.

Questions people actually ask

Is there a file size limit?

No hard limit from us. The practical ceiling is your computer's memory — a merge of a few 100 MB files is usually fine on a modern laptop.

What about password-protected PDFs?

Those can't be opened without the password, so they can't be merged. Unlock them first, then merge.
