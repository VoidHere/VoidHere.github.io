The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Set the length

    16 characters is the modern floor; 20+ where the site allows it.

  2. Choose the character set

    Uppercase, numbers, symbols — and a toggle to skip lookalikes (l/1/I, O/0) when you'll be typing it by hand.

  3. Copy and store properly

    Into a password manager, ideally. The clipboard is a hallway, not a home.

Questions people actually ask

Truly random?

Yes — from the browser's crypto generator, with rejection sampling so every character is equally likely. Slightly more code than the lazy version, meaningfully more entropy.

Should I use a phrase instead?

Long passphrases beat short passwords on strength and memorability both. Pick four diceware words, or take a 20-character random and let the manager remember it.
