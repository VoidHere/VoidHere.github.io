Read a QR code from an image

Point it at a screenshot or photo of a QR code and get the content out — no phone needed.

Runs on your device No uploads, ever Free, no account
The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Drop an image with a QR code

    A clean screenshot is easiest; photos work if the code fills a fair part of the frame.

  2. The content appears

    Links are clickable, text is copyable, Wi-Fi strings are broken into readable parts.

  3. Stay cautious with links

    The preview lets you read a URL before you visit it — the entire reason to decode one somewhere safe.

Questions people actually ask

Can I use my webcam?

This page reads images, not cameras — most phones already do the camera dance natively. Screenshot the code and drop it here.

It didn't find a code — why?

Glare, blur, or a code too small in frame. Crop tighter so the code fills the image and try again.
