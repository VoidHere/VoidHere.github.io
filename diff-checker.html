The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Paste both versions

    Left is the old, right is the new. Order of operations matters only for reading comfort.

  2. Pick the granularity

    Line view for code and lists; word view for contracts and prose, where a comma can matter.

  3. Read the diff

    Removed material in red, added in green, unchanged context left plain.

Questions people actually ask

Can it ignore whitespace and case?

Yes — toggles for both. Turn them on before you accuse anyone of an edit they never made.

Is this the same diff Git uses?

The same algorithm family. Output is a comfortable reading view rather than a patch file you could apply.
