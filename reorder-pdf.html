Reorder PDF pages

The page order the scanner chose, or the one you actually want. Rearrange and save.

Runs on your device No uploads, ever Free, no account
The fine print

This page has no server behind it. Files are read, changed and re-built by your own browser — then they disappear when you close the tab. That's the whole privacy policy, applied.

How it works

  1. Drop the PDF

    Check the page count that appears.

  2. Type the new order

    For a 5-page file, '5,4,3,2,1' reverses it. '2,1,3,4,5' swaps the first two. Every page must appear exactly once.

  3. Download

    The rearranged file downloads with nothing else changed.

Questions people actually ask

What if I get the sequence wrong?

The tool checks it against the page count and refuses with a plain-English message rather than silently skipping pages.

Can I duplicate a page this way?

No — reordering only moves pages. Use Extract Pages twice if you need a duplicate.
