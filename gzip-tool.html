Questions people actually ask

Is .gz the same as .zip?

No — gzip compresses one stream, no file names, no archive. .zip bundles several files. The tools here each do what their format does.

A .tgz file — can this open it?

Not here; .tgz is gzip wrapped around a tar archive, and needs archive handling first. If it matters, say so via the contact page.
